이 블로그는 3-Tier Architecture로 만들어졌어요.

  1. Presentation Tier — Nginx + HTML/CSS/JavaScript: 화면을 보여줘요.
  2. Application Tier — Node.js + Express: 요청을 처리하고 로그인을 확인해요.
  3. Data Tier — MySQL: 글, 댓글, 사용자를 저장해요.

세 계층은 각각 Docker 컨테이너로 실행되고, 브라우저는 Presentation Tier에만 접속할 수 있어요.
